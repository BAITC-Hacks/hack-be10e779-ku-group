## Неизменяемые правила (кратко)

- Приоритет источников: `CASE.md` и ТЗ Задачи → инструкции организатора после выдачи → `docs/hackathon-rules.md` и положение →
  `AGENTS.md`/`CLAUDE.md`/playbook → старые идеи (HYPOTHESIS ONLY). При противоречии — остановиться и назвать его.
- Разработка 13:00–18:00; фиксация в 18:00 независимо от интерфейса платформы; наш финальный push — 17:50.
- Не коммитить и не пушить без прямой команды человека. Секреты не коммитить. Продуктовый код — только после `CASE.md`.
- Проект должен запускаться строго по README без наших аккаунтов; пояснений после дедлайна не будет.

## Только для Claude Code

- Команды проекта (`.claude/commands/`):
  - `/case-intake` — разбор выданного кейса → `CASE.md`, Definition of Done, P0-сценарий, план;
  - `/p0-plan` — раскладка P0 на задачи по владельцам → `TASKS.md`, список `NOT NOW`;
  - `/api-contract` — эндпоинты P0, схемы, ошибки, примеры → `docs/api-contract.md`;
  - `/hourly` — почасовой checkpoint: проверка, запись в `docs/progress.md`, коммит;
  - `/smoke` — проверка основного сценария и запуска с нуля;
  - `/judge` — строгий эксперт: причины недопуска и оценка по 100 баллам отбора;
  - `/freeze` — заморозка: стоп фичам, финальный чек-лист, последний рабочий коммит.
  Процедуры описаны в `docs/playbook.md`, чтобы участник с Codex выполнял их так же.
- Общие разрешения — `.claude/settings.json`. Личные настройки — `.claude/settings.local.json` и `CLAUDE.local.md` (в `.gitignore`).
- `git commit` и `git push` намеренно не в списке авторазрешений: до официального старта в репозиторий ничего не уходит.
- Большие документы из `docs/` читать по необходимости (см. индекс в `AGENTS.md`), а не заранее.
