Выполни процедуру «План P0» из `docs/playbook.md`.

1. Прочитай `CASE.md`. Нет подтверждённых человеком P0-сценария и DoD — остановись и скажи об этом, план не строй.
2. Разложи сценарий по дорожкам: backend · AI/данные · frontend · интеграция · smoke · README.
   У каждой задачи — один владелец (зоны из `AGENTS.md` и `CASE.md`), проверка руками за минуту, номер часа.
3. Порядок — сначала грубый сквозной проход через все слои, потом качество.
4. Всё, что не нужно для DoD, вынеси в `NOT NOW` с пометкой P1/P2. Не предлагай «заодно сделать».
5. Проверь, что один файл не достался двум людям.
6. Сверь с планом по часам из playbook: если задач больше, чем часов, — режь, а не уплотняй.
7. Запиши `TASKS.md` по шаблону из playbook. Если `DECISIONS.md` ещё нет — создай и внеси решение по стеку.
