# Память команды

Каждый участник (и его AI-ассистенты) ведёт свой файл: находки, решения, проверенные факты, тупики.
Пишем **сразу**, как что-то выяснили, и коммитим вместе с кодом — после `git pull` остальные агенты читают это первым делом.

| Файл | Кто | Зона |
| --- | --- | --- |
| `backend.md` | Максим | данные, погода, модель, агент, API |
| `web.md` | Оксана | интерфейс, API-клиент |
| `features.md` | Вова | фичи сверх ТЗ, питч |

Формат записи: `ЧЧ:ММ · [находка|решение|тупик|todo] · суть · доказательство (цифра, файл, ссылка)`.
Решения, влияющие на всех, дублируются одной строкой в `DECISIONS.md`.
